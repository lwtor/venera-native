# Venera Native 1.0.0

Venera Native reaches its first stable release as an Android-native reader for user-managed Venera-compatible comic sources.

- Discover comics through source search, categories, and exploration.
- View comic details, authors, tags, chapter updates, and manage reading lists.
- Read online or download chapters for offline access; import local comic folders.
- Save reading progress across chapters and pages.
- Optionally connect GitHub for manually initiated backup and restore.

Requires Android 8.0 (API 26) or later. Comic sources and their content are selected by users and are not bundled with the app.

The APK is signed with the project's dedicated Release key. It cannot update an installation signed with the shared Debug key.
