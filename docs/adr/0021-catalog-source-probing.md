# ADR-0021：在隔离运行时中试搜漫画源目录

- 状态：已接受
- 日期：2026-11-23

## 背景

用户希望只安装能搜索并打开目标漫画的漫画源。目录脚本在安装前无法由聚合搜索直接调用；临时覆盖已安装来源会破坏正在使用的会话和配置。

## 决策

- `data:source` 可获取并校验目录脚本，返回不持久化的 `SourcePackage`。
- `data:comic` 为目录中的每个来源生成临时运行时 `SourceId`，通过 `SourcePackage.declaredSourceId` 保留并校验脚本声明的 key；调用与应用搜索相同的类型化 `SourceCore.search` 和空筛选请求，保留来源排序及其返回的首屏漫画结果。临时运行时 ID 用作 Host API 的隔离身份，不与已安装会话、Cookie 或来源私有数据共用。
- 单次最多并发探测三个来源；每个来源总探测超时为 120 秒，以覆盖脚本获取、独立元数据读取、运行时安装、搜索及最长 60 秒的详情/章节调用。用户可随时取消。无论成功、失败或调用取消，都卸载临时来源并清理来源私有临时数据。临时 ID 不与脚本声明的真实 ID 冲突，已安装来源状态不被替换。QuickJS 安装时必须校验 `declaredSourceId`，而不是临时运行时 ID；否则所有目录探测都会在运行时安装阶段失败。
- 以来源返回的搜索排序及整页结果作为命中依据，不再用原生端标题或详情/章节做二次过滤。每个来源完成后立即发布结果行；结果页按搜索聚合页的来源分组与横向封面卡片展示，并额外提供添加/更新/切换来源操作。搜索调用失败按失败阶段展示，不能伪装成“无搜索结果”。
- `feature:sources` 通过 `ComicCatalog` 查询当前目录中的来源，只允许用户安装选中的命中项；搜索使用独立全屏路由，不占用目录列表空间。结果汇总按准备、安装、搜索、详情/章节和超时显示失败阶段，普通目录安装流程保持原样。
- 由于临时探测不读取或保存登录凭据，必须登录的来源可能无法试搜；用户仍可按现有流程手动安装并登录。

## 影响

- `:feature:sources` 增加对 `:data:comic` 的依赖，用于调用领域目录搜索契约；不产生 Feature 间依赖，也不在 UI 中拼接脚本。
- 目录搜索只验证搜索、详情和章节目录可以返回，不保证漫画章节页面的图片请求在该设备网络上成功。
